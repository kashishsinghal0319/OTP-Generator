Overview
This is a simple Password Generator built using Python.

The program generates a random password based on the length entered by the user.

Features
User-defined password length
Uses letters, numbers, and special characters
Generates random passwords
Beginner-friendly project
Technologies Used
Python
random module
string module
Example Output
Enter the length of password: 8

Generated Password: iWjYwRY;

Learning Outcomes
Working with Python modules
User input handling
Loops
String manipulation
Random password generation
